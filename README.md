# ILS Rems-Murr Simulation – Download

Leitstellen-Simulation für den Rems-Murr-Kreis: Notrufe mit KI-Anrufern annehmen, Einsätze anlegen, Fahrzeuge alarmieren, Funk – zusammen mit Freunden (bis 8 Spieler).

**Inoffizielles Fan-/Trainingsprojekt** – keine Verbindung zur Integrierten Leitstelle Rems-Murr oder zu Behörden.

## Installieren
1. Unter [Releases](../../releases/latest) die Datei `ILS-RemsMurr-Simulation-Setup-X.Y.Z.exe` herunterladen.
2. Starten und „Ja“ wählen – installiert für dein Benutzerkonto, ohne Administratorrechte, mit Desktop-Verknüpfung.
3. Windows zeigt evtl. „Der Computer wurde durch Windows geschützt“ (SmartScreen, weil das Setup nicht signiert ist): **Weitere Informationen → Trotzdem ausführen**.

## Mitspielen
Der Host schickt dir eine Einladung (`CODE@….trycloudflare.com`). In der App unter **Sitzung beitreten** einfügen – fertig. Gäste brauchen keinen API-Key.

## Updates
Die App prüft beim Start, ob es hier eine neue Version gibt, und installiert sie auf Wunsch selbst. Alle Mitspieler sollten dieselbe Version haben.

Prüfsumme (SHA-256) liegt jedem Release als `.sha256` bei.
